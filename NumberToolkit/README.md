# Number Toolkit in C

A simple and beginner-friendly C program that performs multiple mathematical and number-based operations using a menu-driven system.

## Features

This program can perform:

- LCM (Least Common Multiple)
- GCD (Greatest Common Divisor)
- Odd or Even Check
- Prime Number Check
- Factorial Calculation
- Armstrong Number Check
- Krishnamurthy Number Check
- Palindrome Number Check

---

## Technologies Used

- Programming Language: C
- Compiler: GCC
- Platform: Linux / Ubuntu / Windows

## How to Compile and Run

### Compile

```bash
gcc NumberToolkit.c -o NumberToolkit
```

### Run

```bash
./NumberToolkit
```
