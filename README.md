## 🛠️ How to Run

1. Install a C compiler (e.g., GCC)
2. Compile any file:

   ```bash
   gcc filename.c -o output
   ```
3. Run the program:

   ```bash
   ./output
   ```

---

## ⚠️ Notes

* Some programs use `conio.h`, which may not work on modern compilers.
* You may need to remove `clrscr()` and `getch()` for compatibility.
* These programs are written for learning purposes, not production use.
